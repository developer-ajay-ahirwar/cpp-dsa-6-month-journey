# Arrays

This folder contains C++ array problems organized by difficulty.

## Topics Covered
- Array traversal and manipulation
- Maximum and minimum elements
- Two pointers
- Duplicate removal and frequency counting
- Array rotation
- Hashing and prefix sums
- Kadane's Algorithm
- Greedy techniques
